# PachiAruCG

パチンコ・パチスロ打ちの「あるある」を題材にした架空の3DCGショートアニメ制作プロジェクトです。実機や実在店の名称・ロゴは使用しません。

## 現在の段階
**Prototype 01 — Character Motion Lab**

- 髪なし・肌色・目と口だけの3Dキャラクター
- 裸眼／メガネ切替
- 8種類の動作モードと滑らかな表情・首・肩・腕の補間
- 「隣が当たり、本人は落胆する」短いシナリオ再生
- 打ち手視点／背後視点／横からの視点の切り替え（初期表示は横）
- 通常・ボーナス成立・告知・7図柄入賞・ボーナス消化を区別するリール状態
- 9:16 のスマホ表示、架空の3リール機が同じ島に並ぶ背景
- 画像の切替ではなく、Three.jsで動作する3Dオブジェクト

- `index.html` — アプリのHTML構造

- `AGENTS.md` — シリーズの制作ルール

### リールの固定ルール
リールは `[列][行]` の3×3配列です。通常はオリジナルの色付き長方形のみを使い、上・中・下段のいずれにも同じ図柄の横3つ揃いを作りません。チェリーは使用せず、左リール中段にも出しません。

`通常 → ボーナス成立（未告知）→ 告知（7未入賞）→ 中段7入賞 → ボーナス消化 → 通常` を順番に遷移します。成立だけでは7を表示しません。告知型のランプは告知後に点灯し、ボーナス終了後に消灯します。ノーマル型・告知型とも上乗せ・AT継続など未定義の操作を拒否します。AT型・BT型を追加する場合は別の仕様と実装が必要です。

現在の島は同じ架空の告知型3台です。デモでは隣の台が2.05秒で成立、2.35秒で告知、3.05秒で7入賞、3.65秒で消化、6.65秒で通常へ戻ります。これは本作固有の演出タイミングです。「喜ぶ」では本人の台、隣を見る等の単独動作では隣の台で同じ順序を再生します。説明や操作UIは映像の外に置いています。

### テスト・ローカル確認
Node.js 22以降で、依存パッケージのインストールなしで実行できます。GitHub Actionsでも構文チェックと自動テストを実行します。

```sh
npm run check
npm test
python -m http.server 8000
```

プレビューは `http://localhost:8000` で確認できます。自動テストは1万のシード入力から生成した通常配列、全行の横揃い禁止、左中段チェリー禁止、成立と入賞の分離、ランプ消灯、上乗せ・AT継続の拒否、シナリオの巻き戻し、カメラ切り替えを検証します。

Python PlaywrightとChromiumがある環境では、次のブラウザテストも実行できます。

```sh
python tests/browser-smoke.py --chromium /usr/bin/chromium
```

360×800・390×844・1280×900で、WebGL描画、9:16、横はみ出し、タッチ操作、3視点、一時停止・再開を確認し、画像を `/tmp/pachiarucg-browser/` に保存します。実際のCDNを通常のTLS検証で読み込みます。証明書エラーが発生した場合はエラーを報告し、ルートCA追加やTLS検証無効化は行わずに検証を止めてください。
